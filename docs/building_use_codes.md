# 건물 용도 코드표

`data/building_use_codes.csv`: 브이월드 `usability`(주용도 코드)를 용도 이름으로 바꾸고, 법안 속 용어를 어느 코드에 연결할지 정리한 문서입니다.

## 1. 코드 규칙

- `usability`는 5자리이고, **앞 2자리가 건축법 시행령 [별표 1]의 호 번호**입니다. 예: `18000` = 18호 창고시설
- 사창동 데이터(2,448동)에 나온 코드 15종은 모두 이 규칙과 이름이 맞습니다 (`python collect/check_use_codes.py`로 확인).
- 이 표는 **대분류(호 단위)** 입니다. 세부용도(고시원, 노래연습장 등)는 브이월드 데이터에 없어서 세부용도를 조건으로 하는 법안은 **판정불가**입니다.

## 2. 출처와 확인 상태

| 항목 | 상태 |
| --- | --- |
| 용도 이름·호 번호 | 건축법 시행령 [별표 1](2025.10.1 개정본, 국가법령정보센터)로 확인 |
| 사창동에 나온 15개 코드 | 데이터와 이름 대조 완료 |
| 나머지 코드(05·08·09·12·13·17·21~23·25~29) | 호 번호×1000 규칙으로 만든 값. **건축HUB 공통코드와 대조 전** |
| 23의2 국방·군사시설 | 별표 1에는 있으나 건축HUB 코드를 몰라 표에서 뺌 |
| 예시 시설 목록 | 18호·8호·24호는 별표 원문 확인, 나머지는 2차 자료라 **원문 대조 필요** |

건축HUB 사이트(hub.go.kr)는 자동 열람이 막혀 있어 대조하지 못했습니다. 팀원이 브라우저에서 공통코드(주용도코드)를 열어 `basis` 열이 "번호×1000 규칙"인 행을 확인해 주시면 좋겠습니다.

## 3. 법안 용어 → 코드 연결 (제안)

| 법안 속 용어 | 코드 | 확인 |
| --- | --- | --- |
| 물류터미널, 집배송 시설, 창고(냉동·냉장 포함), 하역장 | 18000 | 별표 1 18호 원문 |
| 여객자동차터미널, 철도시설, 공항시설, 항만시설 | 08000 | 별표 1 8호 원문 |
| 데이터센터, 방송국, 통신용 시설 | 24000 | 별표 1 24호 원문 |
| 전시장(전시시설) | 05000 | 2차 자료 |
| 아파트·연립·다세대·기숙사 | 02000 | 2차 자료 |
| 오피스텔 | 14000 | 2차 자료 |
| 생활숙박시설 | 15000 | 2차 자료 |
| 고시원, 노래연습장, 학원 등 세부용도 | 판정불가 | 대분류 아래 용도라 데이터에 없음 |

## 4. 기존 코드에 대한 제안 (현규님 확인 부탁)

1. `collect/build_web_data.py` 법안 2220631(소방시설법, 물류터미널): `["08000"]` → `["18000"]`. 물류터미널은 운수시설이 아니라 창고시설입니다. 사창동에서 18000은 4동이고 최대 연면적이 108㎡라 이 법안의 판정 숫자는 바뀌지 않습니다.
2. 법안 2220379(건축물관리법, 공장·창고·물류시설): `["17000","18000","08000"]`에서 `08000`은 물류터미널이 18호라 빠져도 될 것 같습니다.
3. `web/admin.js` `USE_NAMES`: `23000`은 현행 이름이 "교정시설"이고, `29000` 야영장시설이 없습니다.

## 5. 한계

- 복합용도 건물은 주용도 하나만 들어 있습니다.
- 대장 미연계 건물(약 13%)은 코드가 비어 판정불가입니다.
- 위 매핑은 법 문구에서 사람이 고른 것이라, 법안이 늘면 표를 계속 보완해야 합니다.
