# 건물 데이터 점검 (사창동)

- 수집일: 2026-10-31
- 출처: 브이월드 WFS `lt_c_bldginfo` (건물통합정보 = 건물 도형 + 건축물대장 표제부 주요 항목)
- 범위: 청주시 서원구 사창동(행정동) 경계 안 **2,448동**
- 코드: `collect/fetch_cheongju_buildings.py` / 결과: `data/bldginfo_사창동.csv`

## 요약 (회의·중간보고용)

- 법안 판정 기준 4개(용도·면적·층수·연도)가 **브이월드 한 곳에 모두 있음** → 건축HUB를 따로 수집하지 않아도 1차 판정 가능
- 건축물대장과 연결된 건물 **86.6%(2,120동)**. 나머지 13.4%(328동)는 속성이 비어 있어 **판정불가**로 표시
- PNU(필지번호) 100%, 좌표 100% → 판정 결과를 건물 단위로 지도에 표시 가능
- 한계: 주용도 하나만 있음(복합용도 건물), 세대수·허가일·용도지역 없음

## 1. 수집 방법

- 동 경계 bbox로 요청. 브이월드는 요청당 2,000건까지만 주므로(STARTINDEX 2000부터 오류) 넘으면 bbox를 4등분해 다시 요청
- `ufid` 기준 중복 제거 → 건물 중심점이 동 경계 안에 있는 것만 저장 (bbox 3,954동 → 2,448동)
- 기존 브이월드 키로 정상 응답 (Referer `http://localhost:3400`)
- `bld_nm`(건물명)은 저장하지 않음: "○○○씨 다가구주택"처럼 개인 이름이 들어간 값이 있음

## 6. 판정이 어려운 항목

1. **대장 미연계 328동(13.4%)**: 용도·면적·층수·연도가 전부 비어 있어 **판정불가**입니다. 원인(무허가, 부속건물, 매칭 실패)은 아직 확인하지 못했습니다.
2. **주용도 하나만 있음**: 1층 근생, 위층 주택 같은 복합용도 건물도 주용도 하나로만 판정됩니다. "해당 용도 바닥면적 합계" 기준이면 건축HUB 층별개요가 필요합니다.
3. **세부용도 없음**: 고시원, 노래연습장처럼 대분류 아래 용도를 조건으로 하면 판정할 수 없습니다.
4. **세대수·허가일·착공일 없음**: "○년 이후 허가" 조건은 사용승인일로 근사하고, 경계선으로 처리하는 것을 제안합니다.
5. **높이 0**: 대장과 연결됐는데 높이가 0인 건물이 80동입니다. 높이 기준 법안에서는 주의해야 합니다.
6. **행정동·법정동 불일치**: 동 경계(`cheongju_emd`)는 행정동(사창동 4311253000)이고, PNU 앞 10자리는 법정동입니다. 경계 안 건물 중 96%(2,351동)만 사창동 법정동 코드(4311210200)이고, 97동은 인접 법정동 코드입니다. 건물 단위 판정에는 영향이 없지만, 동별 집계 기준은 하나로 정해야 합니다.
7. **PNU 하나에 건물 여러 동**: 251개 필지에 2동 이상이 있습니다(최대 20동). 건축HUB와 붙일 때 PNU만으로는 1:1로 맞지 않으므로 `bldrgst_pk`로 대조해야 합니다(건축HUB 번호 체계와 일치하는지는 확인 필요).
8. **데이터 시점**: `regist_day`는 82.7%가 2011-11-28입니다. 사용승인일 최댓값이 2023년이라 최근 신축이나 용도변경이 늦게 반영됐을 수 있습니다. 건축HUB와 표본 몇 건을 대조하면 확인할 수 있습니다.
9. **바탕 지도 파일이 청주 전체가 아님**: `cheongju_buildings_footprint.geojson`에는 사창동 경계 안 건물이 150동뿐입니다(실제 2,448동). 시범 동 지도에는 `bldginfo_<동>.geojson`을 쓰는 것이 맞습니다.
