# 숫자 기준 문장 추출 (규칙 기반)

`collect/extract_criteria.py`가 `data/bills_summary.csv`의 요약문에서 "연면적 1만㎡ 이상", "30년 이상" 같은 숫자 기준을 찾아 `data/criteria_rule.csv`에 저장합니다. AI 추출(서윤)과 비교할 **기준선**이며, 놓치는 문장이 있어도 틀린 값을 만들지 않는 쪽으로 만들었습니다.

## 출력 열

| 열 | 의미 |
| --- | --- |
| `ATTRIBUTE` | 연면적·바닥면적·전용면적·면적(종류미상)·층수·높이·세대수·경과연수 |
| `OPERATOR`, `VALUE`, `UNIT` | 비교 기호(>=, >, <=, <), 환산한 숫자, 단위(㎡·층·m·세대·년) |
| `VALUE_RAW` | 원문 그대로의 구간 (예: `10만㎡ 이상`) |
| `CONTEXT` | 현행(지금 법 설명) / 개정(법안이 바꾸려는 내용) / 미분류 |
| `DELEGATED` | 문장에 "대통령령"이 있으면 Y (시행령 위임, 판정불가 후보) |
| `SENTENCE` | 근거가 된 원문 문장 |

## 환산

- 만·천·억·쉼표: `1만5천` → 15000, `30만` → 300000
- 면적 단위: 제곱미터·m²·㎡는 그대로, 평은 ×3.3058
- 이상·이하·초과·미만·이내·넘는 → >=, <=, >, <, <=, >

## 결과 (678건, 2026-11-14)

- 42개 법안에서 기준 78개 (같은 법안의 같은 기준을 합치면 66개)
- 연면적 7, 전용면적 3, 바닥면적 1, 면적(종류미상) 22, 층수 10, 높이 4, 세대수 25, 경과연수 6
- 문장 성격: 개정 31, 현행 25, 미분류 22. 대통령령 위임 13개

## 한계

- "현행/개정" 구분은 단어 기준이라 틀릴 수 있습니다. `미분류`와 `현행`은 사람이 확인해야 합니다.
- 면적(종류미상)은 정비구역·지구 면적일 수 있어 건물 판정에 바로 쓸 수 없습니다.
- 높이 1.2m(난간)처럼 건물 높이가 아닌 값이 들어올 수 있습니다.
- 사용승인일·준공연도 기준 등 날짜형 기준과, 2개 이상 조건의 AND/OR 관계는 읽지 못합니다.
- 벌칙 문장(징역·벌금)은 제외합니다. 실제 정확도는 서윤님의 정답 라벨(76건)과 비교해 재야 합니다.
