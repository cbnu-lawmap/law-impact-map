# 사창동 용도지역과 지역 기준 법안 후보

`collect/collect_zoning.py`가 브이월드 2D 데이터 API의 용도지역 도형(LT_C_UQ111~114, 지구단위계획 LT_C_UPISUQ161 등)을 사창동 범위로 받아, 건물마다 중심점이 들어가는 용도지역을 붙였습니다. 결과는 `data/zoning_사창동.csv`(필지 2,063개, 건물 2,448동)입니다.

- 브이월드는 해외·클라우드 IP를 받지 않아 GitHub Actions에서는 연결되지 않았습니다(HTTP 000·502). 그래서 이 파일은 저장소 `.env`의 브이월드 키로 이 PC(국내 IP)에서 한 번 수집했습니다. 키는 기록·커밋하지 않았습니다.
- 한 필지가 두 용도지역에 걸치면 "준주거지역|일반상업지역"처럼 둘 다 적었습니다(21필지). 아래 동수는 걸친 건물을 양쪽에 모두 셉니다.
- 판정 규칙(`demo_rules.json`)은 이번에 바꾸지 않았습니다.

## 지역 기준 법안 후보

용도지역 자료로 새로 가를 수 있는 기준만 골랐습니다. 다른 기준(데이터센터 여부, 공사중단 기간 등)은 건물 자료에 없어 함께 써야 하는 경우가 많습니다.

| 법안 | 지역 기준 | 사창동 해당 건물 | 판정 가능성 |
| --- | --- | ---: | --- |
| 2222353 국토계획법, 2222356 건축법 | 주거지역·준공업지역의 데이터센터 입지 제한 | 주거 2,156 / 준공업 0 | 데이터센터 여부(세부용도)가 자료에 없어 지역만으로는 후보 수만 셈 |
| 2202245 공사중단 장기방치 건축물법 | 주거지역 + 공사중단 20년 이상 | 주거 2,156 | 공사중단 여부가 자료에 없음 |
| 2207981 주차장법 | 주차환경개선지구를 주거지역에서 상업지역으로 넓힘 | 상업 307 | 지구 지정은 지자체가 함. 상업지역 건물 수는 바로 셀 수 있음 |
| 2221401 복합용도 특별법 | 일반·근린상업, 준공업, 준주거, 역세권에 복합용도건축구역 | 상업 307 + 준주거 191 | 역세권 범위는 자료에 없음 |
| 2203621, 2206867 공공주택 특별법 | 역세권·준공업지역 복합사업 | 준공업 0 | 역세권 자료 없음 |
| 2220683 도시정비법 | 상업지역 도시정비형 재개발 | 상업 307 | 정비구역 자료 없음 |
| 2203641, 2217802 | 도시지역 건폐율·용적률 | 도시지역 2,448 (전부) | 건폐율·용적률 값이 자료에 없음 |
| 2222880, 2205319, 2222657 | 지구단위계획구역 | 0 | 사창동 건물은 해당 없음 |
| 2221910, 2222933, 2222962, 2208839 | 개발제한구역 | 0 | 해당 없음 |

**정리**: 용도지역만으로 바로 판정 시범에 넣을 수 있는 법안은 없습니다. 대부분 세부용도·지구 지정 등 다른 자료가 함께 필요합니다. 다만 2207981 주차장법(상업지역 307동)과 2221401 복합용도 특별법(상업·준주거 498동)은 "해당 지역 건물 수"를 참고 숫자로 보여 줄 수 있습니다.
