# 법안별 심사 단계

`collect/add_review_stage.py`가 `bills_raw.csv`의 날짜·결과 열로 법안마다 심사 단계를 정하고 `data/bills_stage.csv`로 저장합니다.

## 출력 (`data/bills_stage.csv`)

| 열 | 의미 |
| --- | --- |
| `BILL_NO` | 의안번호 (`bills_summary.csv`와 같은 키) |
| `STAGE` | 심사 단계 |
| `STAGE_DATE` | 그 단계에 해당하는 날짜 |
| `IN_PROGRESS` | 진행 중이면 `Y`, 종결이면 `N` |

## 단계 기준 (위에서부터 먼저 맞는 것)

| 단계 | 기준 | 진행 중 |
| --- | --- | --- |
| 본회의 처리 완료 | `PROC_RESULT` 있음 | N |
| 대안반영폐기(종결) | `CMT_PROC_RESULT_CD` = 대안반영폐기 | N |
| 법사위 처리 / 상정 / 회부 | `LAW_PROC_DT` / `LAW_PRESENT_DT` / `LAW_SUBMIT_DT` 있음 | Y |
| 위원회 심사미료 | 위원회 처리일 있고 결과가 심사미료 | Y |
| 위원회 의결 | `CMT_PROC_DT` 있음 | Y |
| 위원회 상정(심사 중) | `CMT_PRESENT_DT` 있음 | Y |
| 위원회 회부(상정 전) | `COMMITTEE_DT` 있음 | Y |
| 접수 | 위 날짜가 모두 없음 | Y |

## 결과 (대상 법안 678건, 2026-11-13 수집분)

| 단계 | 건수 |
| --- | ---: |
| 위원회 상정(심사 중) | 551 |
| 위원회 회부(상정 전) | 115 |
| 대안반영폐기(종결) | 12 |

- 점검: 위원회 상정일이 처리일보다 늦은 법안은 0건입니다.

## 알아둘 점

- **"처리 결과가 비어 있음 = 계류 중"은 맞지 않습니다.** 대상 678건 중 12건은 대안에 반영되어 폐기된 법안(종결)입니다. 영향 지도에는 `IN_PROGRESS = Y`인 법안만 쓰는 것을 제안합니다.
- 날짜 열의 의미(`CMT_PRESENT_DT` = 위원회 상정일, `LAW_SUBMIT_DT` = 법사위 회부일 등)는 열 이름과 날짜 순서로 해석한 것이며, 열린국회 API 설명서와 대조하지 못했습니다.
- 수집 시점의 스냅샷입니다. 심사 단계는 계속 바뀌므로 다시 수집하면 결과가 달라집니다.
- `bills_raw.csv`는 저장소에 없으므로 이 스크립트를 돌리려면 `collect_bills.py`로 먼저 받아야 합니다.
